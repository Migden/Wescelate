### Wescelate
-----------------------

A simple windows privilege escalation checker. I Found mainstream tools created to much output and would make to much noise on a system
creating my own tool allows for me to change the script or add extra functionality. In Creating this script it also gave me good knowledge on
how these privilege escalation vectors work.
